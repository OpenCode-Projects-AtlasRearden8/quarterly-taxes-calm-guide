# STATUS.md

Built 2026-10-27.

## What was built

**Quarterly Taxes Calm Guide** — an education-only paperwork manual for US
self-employed folks and LLC owners (single-member default-taxation LLCs in
particular), explicitly **never tax advice**, with no number promises anywhere.

Contents:

- `docs/00-start-here.md` — friendly map, honest disclaimers, "three eternal truths".
- `docs/01-estimated-tax-rhythm.md` — the pay-as-you-go groove: who it applies to,
  the four payment windows, safe harbor as a concept, underpayment penalty
  emotionally downsized, payment channels, state side.
- `docs/02-set-aside-percentages.md` — the set-aside bucket; how to *think* about
  picking your own percentage; illustrative labeled example ranges only; worksheet.
- `docs/03-receipts-what-to-keep.md` — three record families; keep/skip triage;
  ADHD-friendly capture system; retention verified-not-guessed.
- `docs/04-1099s-decoded.md` — 1099 family tour (NEC/MISC/K/INT/DIV/R vs W-2),
  ledger-as-ground-truth, mismatch and missing-form checklists, W-9 safety notes.
- `docs/05-quarterly-ritual.md` — three small sessions per quarter (ledger look,
  bucket sweep, paperwork party), panic-mode 10-minute fallback, quarterly
  tracker, annual additions, printable ritual card.
- `docs/06-when-to-call-a-professional.md` — green/yellow/red zone guide, preparer
  types (CPA/EA/attorney/bookkeeper), preparer red flags, consult questions,
  what-to-bring checklist.
- `docs/worksheets/due-date-calendar.md` — fill-in calendar worksheet that
  deliberately has no printed dates: you verify the officials each year.
- `docs/worksheets/panic-meter.md` — levels 1-5 of tax panic, each with tiny
  next-step checklists (level 4 = notices/letters, including scam shapes).
- `docs/glossary.md` — 32 plain-English term entries, cross-linked.

Site: `/site` — a static HTML site generated by `build.py` (zero dependencies,
pure Python stdlib), with a calm warm stylesheet, sidebar nav, prev/next pager,
per-page education-only disclaimer footer, checkbox "job" list styling, and a
print stylesheet for the worksheets. Nothing is published anywhere; viewing is
via a local static server.

Companion positioning (stated in `README.md` and inside the docs):

- `llc-first-year-handbook` owns forming/running the LLC
- `cashflow-simple-ledger` owns the ledger habit
- this guide owns the tax-paperwork rhythm and does not repeat either

## How to run it

```bash
python3 build.py                           # build static site into ./site
python3 -m unittest discover -s tests -v   # run the test suite (33 tests)
./verify.sh                                # both
python3 -m http.server 8000 --directory site   # view locally, then open browser
```

Requirements: Python 3 only (stdlib). No network, no packages, no secrets.

## Known gaps

- The markdown converter covers only the subset this guide uses (headings,
  paragraphs, flat lists incl. checkboxes, pipe tables, blockquotes, fenced
  code, hr, bold/italic/code/links). It is intentionally not a general markdown
  engine; the tests pin the subset.
- No client-side search, no JS anything; long pages are cruised via the sidebar
  and back-to-top (browser) navigation.
- No dark mode.
- Due dates, thresholds, rates: deliberately omitted (education-only). The
  print-styled worksheets are only printable versions of the markdown pages.
- The site is committed for convenience; `build.py` regenerates it from
  `docs/` at any time, and `site/` may lag the docs during edits until rebuilt.
